## Proposed use after owner-approved acquisition

Use the currency distractors, measured knob and visually suitable cap for
development. Reserve a distinct measured object, such as the bronze bracket,
for a future holdout only after qualification. Keep every view of the same
object in one split. Do not treat the gray bracket as novel without a duplicate
check. None of these candidates supplies a verified tiny peg beside a coin.

Keep original file-page URLs, revision identifiers or hashes, attribution and
licenses per image. A coin in the frame does not prove coplanarity; a model
name does not establish dimensions. Obtain caliper measurements for hidden
features. Keep holdout answers and harness code outside test-agent access.
