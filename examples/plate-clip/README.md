# Sample plate clip

A generic tapered plate with a hook and a slot, generated by `photopart.geometry`. It is a stand-in so the scripts have a known solid to check. It is not a model of a commercial part, and the grid image is drawn by the script, not photographed.

Regenerate everything from the repository root:

```bash
python -m photopart.showcase
```

Expected overall size: **51 × 72.6 × 6 mm** (width, height including the hook, thickness). `report.json` is the validator output for that size at a 0.05 mm tolerance.
